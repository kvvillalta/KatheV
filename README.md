# Vidriera A.D.R.

## Descripción

Sitio web desarrollado para **Vidriera A.D.R.**, empresa ubicada en Santa Cruz, Guanacaste, dedicada a la fabricación e instalación de ventanas de aluminio, puertas de vidrio, vitrinas y espejos a medida.



## Features

- Página de inicio.
- Servicios.
- Productos.
- Contacto.
- Diseño responsive.
- Optimización SEO.



## Tech Stack

**Frontend:**
- HTML5
- CSS3
- JavaScript

**Herramientas:**
- Visual Studio Code
- Git
- GitHub
- Vercel
## Installation

1. Descargar o clonar el proyecto.

```bash
git clone https://github.com/kvvillalta/tu-repositorio.git
```

2. Abrir la carpeta del proyecto en Visual Studio Code.

3. Ejecutar el archivo:

```bash
index.html
```

en un navegador web.

## Usage/Examples

El sitio web permite a los usuarios:

- Conocer la información de Vidriera A.D.R.
- Consultar los servicios disponibles:
  - Ventanas de aluminio.
  - Puertas de vidrio.
  - Espejos a medida.
- Visualizar productos y trabajos realizados.
- Contactar con la empresa mediante la información proporcionada.

Ejemplo de uso:

1. Ingresar al sitio web.
2. Navegar por las secciones de servicios y productos.
3. Revisar la información disponible.
4. Contactar a Vidriera A.D.R.
